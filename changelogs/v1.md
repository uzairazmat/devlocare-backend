# Changelog — Version 1 (Phase 1: Backend Foundation)

---

## What's New (For Everyone)

- **The app now connects to the database automatically when it starts.**
  When DevloCare starts up, it checks that it can reach the Supabase database. If the connection fails, the app refuses to start and tells you why — instead of silently breaking later.

- **Health Check page is live.**
  Visit `/api/v1/health` in your browser or any API tool. It will tell you `"status: healthy, db: connected"` if everything is working, or give a clear error if the database is down.

- **All actions are now logged with timestamps.**
  Every important event (startup, shutdown, DB connection, health checks, errors) is printed to the console with a time and label so you always know what the app is doing.

---

## What's Fixed (For Developers)

### `app/core/logging.py` — NEW
- Created a single shared `get_logger()` factory used across all modules.
- Prevents duplicate log handlers being registered on hot-reload.
- Consistent log format: `YYYY-MM-DD HH:MM:SS | LEVEL | module | message`.

### `app/db/session.py` — UPDATED
- `init_db()` now runs `SELECT 1` instead of just opening and immediately closing a connection — this actually verifies the DB responds.
- Added `logger.exception()` in `init_db()` so the full traceback is printed if the DB is unreachable at startup.
- `get_db()` now catches session-level exceptions, rolls back the transaction before re-raising — prevents dirty/hung transactions leaking across requests.

### `app/api/v1/endpoints/health.py` — NEW
- Health check endpoint at `GET /api/v1/health`.
- Reuses the existing `get_db` dependency — no duplicate connection logic.
- Returns HTTP `503 Service Unavailable` with a human-readable message if the DB ping fails.

### `app/api/v1/api_router.py` — NEW
- Central router with prefix `/api/v1`.
- All future endpoint routers (`predict`, `feedback`, etc.) will be registered here — `main.py` stays clean.

### `app/main.py` — UPDATED
- Startup and shutdown events now log what is happening at each step.
- Removed inline DB connection check — delegates entirely to `init_db()`.
- Registers the central `api_router` in one line.

### `app/db/models.py` — NEW
- SQLAlchemy ORM models for all 4 Supabase tables: `users`, `symptom_logs`, `disease_kb`, `feedback`.
- FK `ondelete` behaviours match the SQL schema (`SET NULL`, `CASCADE`).
- `CHECK` constraint on `feedback.rating` (1–5) mirrored from SQL.

### `app/core/config.py` — NEW
- Reads all config from `.env` via `pydantic-settings`.
- Changing a connection string or secret only requires editing `.env` — no code changes.

### Project Setup
- `requirements.txt` populated with all dependencies.
- `.env.example` added — safe template to commit, shows other devs what variables are needed.
- `.gitignore` covers `.env`, `venv/`, `.venv/`, `*.log`, `logs/`, `__pycache__/`, and IDE folders.
